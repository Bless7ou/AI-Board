# Board Reader — AI 수업 어시스턴트

교사가 iPad나 전자칠판에 판서하면, AI가 실시간으로 인식하여 시뮬레이션 애니메이션을 자동 생성하는 **AI 기반 수업 보조 시스템**입니다.

> 현재 버전은 시각화 수요가 가장 명확한 **화학**을 첫 번째 도메인으로 구현한 프로토타입입니다.
> 판서 → 자동 시각화 파이프라인은 특정 과목에 종속되지 않아, 향후 수학(함수·그래프), 물리(역학·전기회로), 생물(세포·DNA 구조) 등 다양한 교과목으로 확장할 계획입니다.

🔗 **[https://aiboard-sandy.vercel.app](https://aiboard-sandy.vercel.app)**

---

## 주요 기능

- **손글씨 OCR + 자동 보정** — Google Cloud Vision API로 화학식·반응식·키워드 인식, 흘려 쓴 글씨도 자동으로 정규화 (예: H20 → H₂O, HCI → HCl)
- **자동 시뮬레이션** — 분자 구조 / 반응식 / 이온결합 / 공유결합 / 전자배치 / 산염기 / 산화환원 7종
- **실시간 제어** — 재생·일시정지, 속도 조절(0.25×~3×), 드래그 플로팅 패널
- **수업 도구** — 스톱워치 / 계산기 / 주기율표를 별도 앱 전환 없이 수업 중 바로 사용 가능
- **수업 요약 패널** — 인식 기록 타임라인 + 수업 내용 자동 요약 및 클립보드 복사
- **미니 캔버스** — 칠판을 지우지 않고 소형 창으로 빠르게 추가 인식

### 1) 판서 인식 (Handwriting OCR)

교사가 iPad 캔버스에 화학식, 반응식 또는 키워드를 손글씨로 작성한 뒤  
**[전체 인식]** 또는 **[부분 인식]** 버튼을 누르면,  
Google Cloud Vision API(DOCUMENT_TEXT_DETECTION)를 통해 이미지를 텍스트로 변환합니다.

이후 자체 화학 파서(parser.ts)가 OCR 오인식을 자동으로 보정합니다.

> 예: `H20 → H₂O` / `C02 → CO₂` / `HCI → HCl`

또한 손글씨 필압·각도에 의한 글자 오인식도 보정하여,  
**글씨가 다소 지저분하게 쓰여도 올바른 화학식으로 변환됩니다.**

---

### 2) 자동 시뮬레이션 생성

인식된 텍스트는 아래 **7가지 유형**으로 분류되어 맞춤 애니메이션이 자동 실행됩니다.

| 판서 예시 | 실행 시뮬레이션 |
|-----------|----------------|
| `H` `He` `C` `Na` `Ne` | 전자 배치도 (H: 1s¹ / He: 1s² / C: 1s²2s²2p² / Ne: 1s²2s²2p⁶ / Na: 1s²2s²2p⁶3s¹) |
| `H2O` `CO2` `NH3` `CH4` | 분자 구조 (PubChem 3D 데이터) |
| `2H2 + O2 → 2H2O` `CH4 + 2O2 → CO2 + 2H2O` | 반응식 애니메이션 (합성·분해·연소·중화·산화환원·이중치환) |
| `NaCl 이온결합` — 염화나트륨(NaCl) · 산화마그네슘(MgO) · 염화칼슘(CaCl₂) · 탄산칼슘(CaCO₃) | 이온결합 시뮬레이션 |
| `H2O 공유결합` — 산소 분자(O₂) · 질소 분자(N₂) · 메테인(CH₄) · 다이아몬드(C) | 공유결합 시뮬레이션 |
| `HCl + NaOH` `H2SO4 + KOH` `산염기` | 산염기 반응 |
| `Zn + CuSO4` `Fe + CuSO4` `Mg + HCl` `산화환원` | 산화환원 반응 |

PubChem API 연동으로 내장 데이터베이스에 없는 화학식도 구조 데이터를 자동으로 불러옵니다.

---

### 3) 인터랙티브 제어

수업 진행 중 교사가 시뮬레이션을 직접 제어할 수 있도록 설계된 구조입니다.

- **재생 / 일시정지**
- **속도 조절** (0.25× ~ 3×)
- **드래그 가능한 플로팅 패널**
- **색상 및 펜 굵기 조절**
- **수업 기록 타임라인 생성**
- **시뮬레이션별 프리셋 선택** — 전자배치 12종 원소 / 분자구조 8종 / 반응식 6가지 유형 × 다수
- **시뮬레이션 내 미니 캔버스 직접 입력** — 칠판을 지우지 않고 시뮬레이션 대상 즉시 변경 가능

---

### 4) 수업 요약 패널

인식된 내용을 시간순으로 기록하고,  
수업 종료 후 주요 개념을 자동으로 정리하여 **클립보드로 복사**할 수 있습니다.

---

### 5) 미니 캔버스

전체 칠판을 초기화하지 않고도, 플로팅 창으로 소형 판서 입력창을 열어  
화학식을 빠르게 인식하고 시뮬레이션을 바로 전환할 수 있습니다.

---

### 6) 수업 도구

별도 앱 전환 없이 수업 중 바로 활용할 수 있는 내장 보조 도구입니다.

- **스톱워치** — 실험 시간 측정 및 수업 타이머
- **계산기** — 화학 계산(몰질량, 농도 등) 즉시 처리
- **주기율표** — 원소 정보 빠른 참조

## 기술 스택

- **Frontend** — React 19 + TypeScript + Vite
- **OCR** — Google Cloud Vision API (DOCUMENT_TEXT_DETECTION)
- **화학 데이터** — PubChem API + 자체 원소·분자 데이터베이스 (1~6주기)
- **배포** — Vercel (서버리스 프록시 포함)
